# Trivia-CLI
- a simple trivia game built with Javascript and Node.JS

## Features
- presents trivia questions one at a time.
- accepts answers through the terminal.
- checks answers and provides immediate feedback.
- accepts answers regardless of the letter case.
- gives the player 15 seconds to answer each question.
- reveals the correct answer when the time runs out.
- tracks the player's score throughout the entire game.

## Requirements
- Node.js installed in your computer.

## Steps
1. Clone or download this repository.
2. Open the project folder in your terminal.
3. Run the game using : '''bash npm start
